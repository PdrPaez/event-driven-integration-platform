# Contributing

Use `feature/*`, `fix/*`, `refactor/*` or `test/*` branches into `dev`, then promote validated changes to `main`. Keep commits small and tagged (`[FEAT]`, `[FIX]`, `[TEST]`, `[DOCS]`, `[CHORE]`). Run `ruff check .`, `pytest` and `npm run lint && npm run build` before opening a pull request.
